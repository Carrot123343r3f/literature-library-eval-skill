# Contributing

Thanks for helping improve Engineering Literature Library Audit.

## Good first contributions

- Report a reproducible bug with the input files and command used.
- Add an engineering-domain profile or venue mapping.
- Improve a translation or a user-facing explanation.
- Add a test for an edge case in the audit indicators.
- Propose an adapter for a literature source, without committing credentials.

## Before opening a pull request

1. Keep API keys, tokens, private full text, and absolute local paths out of commits.
2. Add or update tests when changing audit behavior.
3. Run `pytest -q` from the repository root.
4. Explain the evidence boundary and any remaining manual-verification steps.

Please use the issue templates for bug reports and feature requests. Small,
focused pull requests are easier to review.
