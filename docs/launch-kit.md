# Launch kit

This page contains reusable material for sharing the project with engineering
researchers. Adapt the wording to the community and always link to the GitHub
repository.

## Short description

Engineering Literature Library Audit checks whether a literature library and
its search evidence are ready to support an engineering review. It reports
coverage, saturation, balance, recency, impact signals, usability, and the
next actions needed to close evidence gaps.

## Suggested post

I built an open-source tool for a problem that appears late in many literature
reviews: after collecting hundreds of papers, you still do not know whether a
whole sub-direction was missed.

Engineering Literature Library Audit runs a reproducible, evidence-graded
check before writing. It does not replace Zotero or expert screening; it shows
what the current library supports, what is not assessable yet, and what to do
next. A local demo is included and runs without an API key.

Try it: https://github.com/Carrot123343r3f/literature-library-eval-skill

Feedback from engineering researchers, systematic-review authors, and AI-for-
research users is especially welcome.

## Where it fits

Share first in communities where the problem is already discussed: engineering
research groups, systematic-review communities, open-source AI-for-research
groups, and discipline-specific forums. Lead with a concrete use case and the
demo report; avoid posting the same message repeatedly.

## Before sharing

- Confirm the demo command works from a clean clone.
- Link directly to the example report.
- Mention the supported engineering scope and the out-of-scope disciplines.
- Invite bug reports and use-case feedback, not only Stars.
